02

使用说明：从开通到日常

  1. 确定档位

    先数设备：同一个人手上通常是一台电脑加一到两台移动设备；若还有平板或家里的另一台机器，就要把数量往上算。再估流量：以每月实际使用为准，不要以偶尔的一次大文件下载为准。

  2. 完成开通

    按照所选档位完成订阅流程后，账号即对应到你选择的档位。月付与年付的差别体现在结算周期上，权益内容以档位说明为准。

  3. 在设备上配置

    客户端的获取方式与具体下载位置，请以官方渠道的说明为准；本页不提供下载链接，也不代为确认版本号。若手上已有对应客户端，按客户端内的引导完成配置即可。

  4. 日常维护

    定期看一眼本月的流量使用情况与在线设备数，接近上限时再考虑是否调整档位。档位调整的可行性与生效方式，以账号内实际可操作的项目为准。

05

常见问题，按主题分开摆

关于档位与价格

三档之间的差别到底在哪？

主要在两处：每月流量额度与同时在线设备数。基础版为 100GB 与 3 台，旗舰版为 300GB 与 5 台，团队版为 1000GB 与 20 台。其余差异体现在流媒体解锁范围、线路类型与支持方式上，具体条目已在方案区逐条列出。

年付会不会改变权益内容？

年付只改变结算周期与总额写法，不改变档位内的权益边界。基础版 ¥150 / 年、旗舰版 ¥350 / 年、团队版 ¥850 / 年，对应的是同一档位。

关于开通与配置

开通之后要做的第一件事是什么？

先在客户端侧完成配置，再回到账号里核对当前档位与设备数是否吻合。两步顺序反过来，容易在配置时才发现档位不对。

客户端从哪里获取？

本页不提供下载链接，也不列版本号。请以官方渠道的说明为准；若官方说明与本页文字有出入，以官方为准。

关于用量与调整

怎么判断自己该选哪一档？

先看设备数，再看月流量。若设备数已经在 4 台左右，基础版的 3 台在线就会成为限制；若每月流量长期在 100GB 以内，也不必提前上到团队版。以自己过去一个月的实际情况作参照，比预测未来更可靠。

接近流量上限了怎么办？

先确认是否是少数设备占用较多，再考虑是否调整档位。档位调整的可行性与生效方式，以账号内实际可操作的项目为准，本页不代为承诺具体处理结果。
